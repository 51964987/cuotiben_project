# 错题本（拍照收集 → 重新排版打印重做）

为孩子收集平时做错的题目，AI 识别后去掉手写痕迹重新排版，打印成干净的 A4 重做卷。
重复出错的题优先出卷，距上次做错超过 N 天的题自动再次出现；连续做对自动移出错题本。

## 功能

- **拍照录入**：手机浏览器直接调起相机拍照，智谱 GLM-4V 自动识别题干（LaTeX 公式）与答案，可手动修正
- **图形题**：编辑页在原照片上框选几何图/线段图区域，自动裁剪为题目附图
- **题库管理**：按状态/关键词筛选、编辑、删除；记录错误次数与上次做错时间
- **组卷**：智能选题（间隔期 + 错误次数优先）/ 全部错题 / 手动勾选，三种方式
- **打印**：A4 排版，每题留解答区，答案与解析自动放最后一页（家长页），浏览器 Ctrl+P 打印或存 PDF
- **批改**：逐题勾选对/错，自动累计错误次数与连续做对次数

## 安装与启动（Windows）

```powershell
cd d:\biancheng\project\cuotiben_project
pip install -r requirements.txt
.\start.bat        # 或 python run.py
```

服务监听 `0.0.0.0:8000`：

- 本机访问：<http://localhost:8000>
- 手机访问：手机连同一 WiFi，浏览器打开 `http://电脑IP:8000`（电脑 IP 用 `ipconfig` 查看；若打不开，在 Windows 防火墙放行 8000 端口）

## 配置

在「设置」页填写：

| 配置 | 说明 |
|---|---|
| API Key | 智谱开放平台 <https://open.bigmodel.cn> 注册获取；`glm-4v-flash` 免费 |
| 识别模型 | 默认 `glm-4v-flash`，追求准确可换 `glm-4v-plus` |
| 默认间隔天数 | 距上次做错超过 N 天才再次出卷（0 = 不限） |
| 连续做对次数 | 连续做对多少次后自动移出错题本（默认 2） |

未配置 Key 时仍可拍照 + 手动录入，不影响其他功能。

## 使用流程

1. **手机**：拍照录入 → 核对识别结果（可框选图形）→ 保存
2. **电脑**：组卷 → 打开试卷 → `Ctrl+P` 打印（勾选"背景图形"，A4 纵向）
3. 孩子做完后：试卷 → 批改 → 逐题勾选对/错
4. 做错的题错误次数 +1，下次组卷自动优先出现

## 技术栈与目录

Python FastAPI + SQLite + Jinja2 + 原生前端（KaTeX 渲染数学公式），单机零外部依赖。

```
app/
  main.py       # 全部路由
  db.py         # SQLite 与数据目录
  ai.py         # GLM-4V 识别
  templates/    # 页面（含打印排版）
  static/       # 样式与裁剪脚本
data/           # 运行时生成：cuotiben.db、photos/（原照片）、figures/（裁剪图形）
```

数据全部存本地 `data/` 目录，备份该目录即可。
